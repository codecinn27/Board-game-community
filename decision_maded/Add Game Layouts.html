Add Game Layouts

Add a game I own: three layouts

The same add page (the Add tab, /games/new) drawn three ways. Use the switch to see each layout when the game is already on the shelf, and when nobody has it yet. Example games and names only.

A · Search first Recommended

Only a search box at first. The manual form opens from a link, with the typed name filled in.

  • Steers people to the existing record, so fewer duplicates
  • One extra tap when the game is new

B · Both always visible

Search on top, the full form below it, from the start.

  • Fastest when you know the game is new
  • Long page on a phone; easy to skip the search

C · Form first, live hint

Just the form. Typing the name shows matching games right under the field.

  • One screen, one flow
  • The match is easy to miss while filling the form
